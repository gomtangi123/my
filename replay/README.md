# 리플레이 (웹)

사진을 한꺼번에 고르면 **흔들린 사진·비슷한 사진·스크린샷을 알아서 빼고, 날짜별로 엮어서
1080×1920 세로 영상**으로 만들어 주는 웹앱입니다.

**사진은 기기 밖으로 나가지 않습니다.** 분석도 영상 만들기도 전부 브라우저 안에서 합니다.
서버가 필요 없어서 정적 호스팅(GitHub Pages 등)에 그대로 올리면 됩니다.

## 써 보기

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 됩니다.

```bash
# 또는 로컬 서버로 (휴대폰에서 같은 와이파이로 접속해 볼 때)
python -m http.server 8000 --directory replay
```

## 하는 일

```
사진 고르기 (여러 장 / 폴더 / 끌어다 놓기)
   │
   ├─ 날짜·위치     EXIF → 파일 이름(KakaoTalk_20260914_...) → 파일 수정 시각 순으로
   ├─ 못 쓰는 사진  스크린샷(PNG·기종 없음·화면 비율), 너무 어두움, 흔들림(라플라시안 분산)
   ├─ 연속 촬영     10분 안 + 지각 해시(dHash)가 비슷하면 가장 선명한 한 장만
   └─ 분량 맞추기   날짜·3시간 공백·20km 이동으로 장면을 나누고 장면 크기에 비례해 고르게
   │
   ▼
타임라인  분위기(감성 / 신나는 / 잔잔한)별 길이·전환·줌, 날짜 바뀔 때 자막, 제목·엔딩
   │
   ▼
캔버스에 그려 MediaRecorder로 녹화 → mp4 (크롬·사파리) / webm (파이어폭스)
```

편집 화면에서 사진을 빼거나(✕), 다시 넣거나(+ 넣기), 순서를 바꾸고(◀ ▶),
기간·분위기·제목·최대 사진 수·배경음악을 바꿀 수 있습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `js/exif.js` | JPEG EXIF에서 촬영 시각·기종·GPS 읽기, 파일 이름 날짜 |
| `js/select.js` | 사진 고르기 (순수 함수 — node에서 테스트) |
| `js/timeline.js` | 분위기 프리셋, 시간축 배치, 기본 제목 (순수 함수) |
| `js/analyze.js` | 브라우저에서 선명도·밝기·해시·썸네일 계산 |
| `js/player.js` | 캔버스 그리기, 재생, 녹화 |
| `js/app.js` | 화면 연결 |

## 알려진 한계

- **녹화는 실시간**이라 1분 영상은 1분 걸립니다. 녹화 중엔 탭을 띄워 둬야 합니다
  (백그라운드 탭은 브라우저가 멈춥니다).
- **HEIC(아이폰 원본)** 는 사파리에서만 열립니다. 크롬에선 "열 수 없는 파일"로 빠집니다.
  아이폰 사진 앱에서 고를 땐 보통 JPEG로 바뀌어 넘어옵니다.
- 휴대폰 브라우저는 사진을 넘길 때 **위치(GPS) 정보를 지우는 경우가 많습니다.**
  그때는 날짜로만 장면을 나눕니다.
- 배경음악은 사용자가 가진 파일을 씁니다. 앱이 음원을 제공하려면 저작권이 정리된 음원이 필요합니다.
- 아직 실제 휴대폰에서는 검증하지 않았습니다.
